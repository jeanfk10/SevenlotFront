# SevenlotFront

Fronts de compra de rifas para la plataforma LottoGE.

| Front | Carpeta | Qué es |
| --- | --- | --- |
| Minimalista | [`fronts/minimalista/`](fronts/minimalista/) | Compra en una sola página: boletos, datos y pago en el mismo recuadro. Carrusel de fotos, resultados aprobado / reservado / rechazado. |
| Estándar | [`fronts/estandar/`](fronts/estandar/) | Con la marca de LottoGE, como la página principal de lottoge.net: blanco, azul marino y coral, letra Plus Jakarta Sans, tarjetas redondeadas. Mismo flujo. |
| Vibrante | [`fronts/vibrante/`](fronts/vibrante/) | La llamativa: el color del rifero en bloques grandes, letras condensadas y botones que se hunden. Mismo flujo. |
| Neón | [`fronts/neon/`](fronts/neon/) | Noche sobria en grafito y plata: aurora suave, premio con brillo metálico, cintas que corren y borde fino en el color del rifero. Mismo flujo. |
| Pop | [`fronts/pop/`](fronts/pop/) | Estilo sticker en tonos arena, salvia y piedra: bordes gruesos, figuras flotando y botones que rebotan. Mismo flujo. |
| Experimental | [`fronts/experimental/`](fronts/experimental/) | Otra distribución: fotos a pantalla completa como historia, porcentaje vendido a la vista, hoja con pestañas Comprar, Premios e Info, premios en escalones. Mismo flujo. |
| Prototipo Dubái | [`rifa-dubai/`](rifa-dubai/) | Primer prototipo, temático. Solo referencia. |

Cada front se adapta solo: vista móvil en teléfonos y vista de escritorio en computadoras. Trae una `vista-previa/` con todas las pantallas en iPhone o en Mac y una carpeta `front/` lista para exportar. Ver el README de cada uno.
