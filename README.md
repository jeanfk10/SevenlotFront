# SevenlotFront

Fronts de compra de rifas para la plataforma LottoGE.

| Front | Carpeta | Qué es |
| --- | --- | --- |
| Minimalista | [`fronts/minimalista/`](fronts/minimalista/) | Compra en una sola página: boletos, datos y pago en el mismo recuadro. Carrusel de fotos, resultados aprobado / reservado / rechazado. |
| Vibrante | [`fronts/vibrante/`](fronts/vibrante/) | La llamativa: el color del rifero en bloques grandes, letras condensadas y botones de juego. Mismo flujo. |
| Elegante | [`fronts/elegante/`](fronts/elegante/) | La sobria: fondo blanco, títulos con serifa y tarjetas suaves. Mismo flujo. |
| Prototipo Dubái | [`rifa-dubai/`](rifa-dubai/) | Primer prototipo, temático. Solo referencia. |

Cada front trae una `vista-previa/` (todas las pantallas en iPhones) y una carpeta `front/` lista para exportar. Ver el README de cada uno.
